# v0.6.0 统一认证与 RBAC 适配

## 目标

让 openZetcX 使用 openZetcWeb 0.6.0 的统一账号、角色、权限和部门授权结果，并覆盖 Agent、Skill、知识库与 MCP 资源入口。

## 验收清单

- [x] 登录同时获取用户身份与 RBAC 快照。
- [x] 会话验证能刷新角色、权限和资源缓存。
- [x] Agent、Skill、知识库、MCP 按权限显示。
- [x] 无权限的目录、同步和查询请求在本地明确拒绝。
- [x] 所有实际资源访问仍由 openZetcWeb 服务端强制鉴权。
- [x] 旧版会话可安全迁移且密码不落盘。
- [x] 类型检查、相关单元测试、Lint 和前端构建通过。
