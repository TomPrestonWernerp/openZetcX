# 企业突发环境事件应急预案编制工作流（三书一体版）

## ⚡ ⚠️ 最高优先级规则：python-docx 的技术限制

### 规则C：禁止使用"load + append"方式向已有文档中插入内容
**python-docx 没有"在段落之间插入"的功能**。`doc.add_paragraph()` 和 `B()` 永远只能向文档末尾追加新段落。
- ❌ **禁止**先创建包含12个章节的文档，再用 `doc = Document(FPATH)` + `B("扩展内容")` 的方式把内容"塞进"某个中间章节
- ✅ **正确做法**：修改各章节的**生成脚本**，在对应章节的 `B()` 调用之间直接加入新的 `B()`，然后**从头重新运行整套生成脚本**
- ✅ 如果所有扩展内容都在同一个脚本里按章节顺序生成，则顺序自然正确

### 规则A：扩充分段内容必须插入对应章节位置
### 规则B：使用单一完整的生成脚本

---

## 概述

本技能用于为工矿企业编制或修订突发环境事件应急预案。**作为「三书一体」的主文档**，生成应急预案的同时需协同同步生成环境风险评估报告和应急资源调查报告。

**参考实例：** 浙江天宁合金材料有限公司应急预案，全文含附件约 **3.2万中文字**、443段、20个表格。

## 三书一体协作模式

### 数据共享架构

```
                     ┌─────────────────────────────┐
                     │      GLOBAL 数据表            │
                     │  (三书共用同一个数据源)          │
                     │                               │
                     │  ├ company/address/法人等      │
                     │  ├ chemicals[] 风险物质清单     │
                     │  ├ q_value/risk_level 风险等级  │
                     │  ├ pool_V1~V5 应急池核算参数    │
                     │  ├ materials[] 物资清单         │
                     │  ├ team{} 应急队伍              │
                     │  └ sensitive_list[] 敏感目标    │
                     └──────────┬──────┬──────┬──────┘
                                │      │      │
                   ┌────────────┘      │      └────────────┐
                   ▼                   ▼                   ▼
        ┌──────────────────┐ ┌──────────────┐ ┌──────────────────┐
        │ 应急预案 DOCX     │ │ 风险评估 DOCX │ │ 资源调查 DOCX     │
        │ (12章+附件)       │ │ (8章)        │ │ (6章+附件)        │
        └────────┬─────────┘ └──────┬───────┘ └────────┬─────────┘
                 │                   │                   │
                 └──────────────┬────┼───────────────────┘
                                ▼    ▼
                    ┌─────────────────────────┐
                    │  自检门 Cross-Check      │
                    │  D-01~D-09 三书一致性   │
                    └─────────────────────────┘
```

### 数据一致性保障（D-01~D-09）

| 检查点 | 应急预案章节 | 风险评估报告章节 | 资源调查报告章节 |
|:------:|:-----------:|:--------------:|:--------------:|
| D-01 企业名称 | 2.1 | 3.1 | 2.1 |
| D-02 物质清单 | 2.5/3.2 | 3.5 | 2.2（摘要） |
| D-03 Q值 | 3.2.1/3.3.1 | 7.3.1/7.4.1 | — |
| D-04 风险等级 | 3.4 | 7.5 | 2.2 |
| D-05 应急池容量 | 4.2 | 5.2.3 | 3.4.2 |
| D-06 化学品储量和 | 3.2 | 3.5 | — |
| D-07 员工人数 | 2.1 | 3.1 | 2.1 |
| D-08 设备列表 | 2.5 | 3.2.5 | — |
| D-09 固废数据 | 2.6 | 3.2.6 | — |

**⚠️ 工作流程要求：** 当为本企业生成应急预案时，必须同时生成风险评估报告和资源调查报告。三份脚本使用**同一个 GLOBAL 数据源**返回同一个值，天然通过 D-01~D-09。

### 数据变更流程

```
发现有数据要修改（如物质清单变化）
    ↓
修改 GLOBAL 表（一个地方）
    ↓
重新运行全部3个生成脚本
    ↓
自检门自动校验3份数据一致
    ↓
输出3份DOCX + 3份自检JSON
```

**严禁**单独修改某一份文档的数据而不更新其他两份。

## 阶段二：数据计算（规则引擎硬算，LLM禁止）

### 步骤4：计算Q值
- 公式：`Q = w₁/W₁ + w₂/W₂ + ... + wn/Wn`
- 涉气/涉水分类计算
- Q值水平：Q<1→Q0(一般)/1≤Q<10→Q1/10≤Q<100→Q2/Q≥100→Q3

### 步骤5：M值评估
- 生产工艺评分（HJ 941-2018 表1）
- 大气防控措施评分（表2）
- 水防控措施评分（表6）
- M水平：M<25→M1/25≤M<45→M2/45≤M<65→M3/M≥65→M4

### 步骤6：E值判定
- 大气E值（表4）：E1/E2/E3，基于500m和5km人口
- 水E值（表7）：E1/E2/E3，基于下游10km敏感程度

### 步骤7：风险等级确定
- 矩阵判定（表5）
- 等级表征格式：`重大[重大-大气(Q1-M3-E1)+较大-水(Q2-M2-E2)]`

### 步骤8：应急池核算
- 公式：`V总 = (V₁+V₂-V₃)max + V₄ + V₅`
- ——此值与风险评估报告5.2.3、资源调查报告3.4.2共用（D-05）

### 步骤9：搜索补充区域信息
- 自然环境、环境质量现状、政府应急联络

## 第五章：审核规则驱动生成（Self-Audit Gate）

### 5.1 核心原则
**不再「想写什么就写什么」，而是「审核规则要求什么就写什么」。**

### 5.2 自检门升级（三书交叉验证版）

```
GLOBAL数据准备 → 三份脚本同步生成 → 格式排版 → 自检门 → 输出三份DOCX
                                              │
                                              ├── 标准引用时效性检查（19标）
                                              ├── Q/M/E 数值校验
                                              ├── D-01~D-09 三书数据一致性
                                              ├── 行业物质遗漏检查（E族）
                                              └── 不通关 → 修正后三份重跑
```

### 5.4 自检通过标准

| 检查项 | 方法 | 通过标准 |
|:------|:----|:--------|
