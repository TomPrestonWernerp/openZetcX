# 环境应急资源调查报告 编制与自审工作流

## 三书一体定位

环境应急资源调查报告是「三书一体」中的**资源保障文件**，回答「有什么可用」。

| 维度 | 本报告 | 关联文档 |
|:----|:------|:--------|
| 核心数据 | 物资清单 → 应急池核算 → 队伍调查 → 社会资源 | 与应急预案共用 GLOBAL 数据表 |
| 交叉校验 | D-01/D-02/D-04 | 企业名/物质清单/风险等级三书一致 |
| 审核规则 | B-01~B-13, F-08, E-04/E-05/E-12 | 全量覆盖14条专属规则 |

## 输入要求

### GLOBAL 共享数据表（与应急预案、风险评估报告共用）

| 字段 | 说明 | 来源 | 对应规则 |
|:----|:----|:----|:-------:|
| company | 企业名称 | 企业提供 | D-01 |
| chemicals[] | 风险物质清单（摘要） | GLOBAL共享 | D-02 |
| risk_level | 环境风险等级 | GLOBAL共享 | D-04 |
| materials[] | 应急物资清单（名称/规格/数量/位置/状态） | 行业模板预填+企业确认 | B-01, B-02 |
| facilities[] | 应急设施（围堰/应急池/切换阀/喷淋塔等） | 企业提供 | B-04~B-10 |
| pool_V1~V5 | 应急池核算参数 | 企业提供 | B-04~B-10, F-08 |
| team{} | 应急队伍（总指挥/组长/成员/联系方式） | 企业提供 | B-11 |
| external[] | 外部社会资源（单位/电话/能力） | 企业提供 | B-12 |
| ppe_special | 行业专用防护物资（解毒剂/葡萄糖酸钙等） | 行业规则触发 | E-04, E-05, E-12 |

**⚠️ 红线：** B-04~B-10（应急池核算）全部为规则引擎硬算，禁止LLM参与。F-08为否决项——应急池未核算直接判定不通过。

## 文档结构（6章+附件）

### 第1章 调查概述（表格式，≤1页）
- 调查时间/负责人/过程/结果（格式参考环办〔2014〕34号附录D）
- 资源匹配结论（完全满足/满足/基本满足/不能满足）

### 第2章 企业基本信息与风险概况（≥500字）
- 2.1 基本信息（单位名称/地址/法人/行业/员工/物资库位置→D-01）
- 2.2 主要风险物质与风险等级（从GLOBAL共享→D-02, D-04）
- 2.3 应急组织体系概述（总指挥/专业组/人员总数）
- **必须包含的表格：** 企事业单位基本信息表

### 第3章 环境应急资源清单（≥1,500字）
- 3.1 应急物资清单
  - 3.1.1 个人防护物资（防化服/SCBA/防毒面具/手套/护目镜）
    - ⚠️ 含氰企业触发E-04：必须配解毒剂（亚硝酸异戊酯+硫代硫酸钠）
    - ⚠️ 含HF企业触发E-05：必须配葡萄糖酸钙凝胶
  - 3.1.2 堵漏与收集物资（吸附棉/沙包/潜水泵/收集桶）
  - 3.1.3 中和与处置物资
    - ⚠️ 含酸/碱企业触发E-12：必须配中和剂（碳酸钠/氢氧化钠）
- 3.2 应急监测设备（pH计/气体报警器/在线监测）
- 3.3 应急通讯与照明（对讲机/应急灯/扩音喇叭）
- 3.4 应急设施
  - 3.4.1 围堰与防渗（储罐区/危废仓库/车间）
  - 3.4.2 应急池核算（V总公式→F-08否决检查）
    ```python
    V_total = (V1 + V2 - V3) + V4 + V5
    # 必须包含：公式原文→参数含义→分步计算→与现有容量对比结论
    ```
  - 3.4.3 雨污切换设施（切断阀位置/操作方式）
- **必须包含的表格：** 应急物资清单表（至少8列）、应急设施一览表、应急池核算表

### 第4章 应急救援队伍（≥1,000字）
- 4.1 应急组织结构（指挥中心+各专业组设置→B-11）
- 4.2 日常管理（培训/演练/档案管理）
- 4.3 应急分工与联系方式（各组职责详细展开）
- **必须包含的表格：** 指挥中心联系表、专业组联系表、专家联系表

### 第5章 外部联动社会资源（≥300字）
- 5.1 可依托的外部救援力量（消防/环保/医院/应急局→B-12）
- 5.2 邻近企业互助协议（若有→附协议文本；若无→建议签订）
- **必须包含的表格：** 可请求援助部门联系方式表

### 第6章 应急资源管理维护制度（≥600字）
- 6.1 经费保障制度
- 6.2 物资更新维护制度
- 6.3 培训与演练制度
- 6.4 档案管理制度

### 附件
- 应急物资分布图
- 应急疏散路线图

## 物资清单预填规则

不同行业触发不同的物资预填模板：

| 行业特征 | 必须预填的物资 | 规则触发 |
|---------|-------------|:-------:|
| C33 含铬 | 焦亚硫酸钠（铬酸雾解毒剂） | E-01, E-02 |
| C33 含氰 | 亚硝酸异戊酯、硫代硫酸钠、SCBA | E-03, E-04 |
| C33 含HF | 葡萄糖酸钙凝胶 | E-05 |
| C33 含酸/碱 | 碳酸钠（中和剂）、氢氧化钠 | E-08, E-12 |
| C33 重金属 | EDTA、重金属捕捉剂 | E-07 |

## 自检门（Self-Audit Gate）

| 检查项 | 方法 | 通过标准 |
|:------|:----|:--------|
| 应急池核算 | 规则引擎重算 | V总与实际值差距<5%且F-08不触发 |
| 物资清单完整性 | 行业模板比对 | 至少覆盖行业TOP15物资 |
| 专项物资检查 | 规则触发 | 含氰→E-04有解毒剂；含HF→E-05有葡萄糖酸钙；含酸碱→E-12有中和剂 |
| 队伍完整性 | 格式检查 | 总指挥+≥3个专业组+全部联系方式 |
| 外部资源 | 格式检查 | ≥5个可求助单位 |
| 数据一致性 | GLOBAL比对 | D-01, D-02, D-04 PASS |

## 审核规则覆盖率

| 族 | 已覆盖 | 规则编号 |
|:--|:-----:|:--------|
| B（应急资源调查） | 13/13 | B-01~B-13 |
| F（否决项） | 1/12 | F-08（应急池核算） |
| D（数据一致性） | 3/9 | D-01, D-02, D-04 |
| E（行业特异性触发） | 3/13 | E-04, E-05, E-12（触发式） |
