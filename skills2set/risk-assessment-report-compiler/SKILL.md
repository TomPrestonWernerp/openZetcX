# 环境风险评估报告 编制与自审工作流

## 三书一体定位

环境风险评估报告是「三书一体」中的**风险量化文件**，回答「风险有多大」。

| 维度 | 本报告 | 关联文档 |
|:----|:------|:--------|
| 核心数据 | Q/M/E值 → 等级确定 → 差距分析 | 与应急预案共用 GLOBAL 数据表 |
| 交叉校验 | D-01~D-09 | 与预案+资源报告三书一致 |
| 审核规则 | A-01~A-18, F-01/F-02/F-04/F-06/F-07, E-01~E-13 | 全量覆盖23条专属规则 |

## 输入要求

### GLOBAL 共享数据表（与应急预案、资源调查报告共用）

| 字段 | 说明 | 来源 | 对应规则 |
|:----|:----|:----|:-------:|
| company, address, 法人等 | 企业基本信息 | 企业提供 | D-01 |
| chemicals[] | 风险物质清单（名称/CAS/浓度/最大量/临界量） | 企业提供 | A-01~A-05, F-04 |
| q_air, q_water | 涉气/涉水Q值 | 规则引擎计算 | F-01/F-02, A-06~A-08, D-03 |
| m_process_score | 生产工艺评分 | 规则引擎 | A-09~A-12 |
| m_air_items[] | 大气防控措施评分 | 规则引擎 | A-09~A-12 |
| m_water_items[] | 水防控措施评分 | 规则引擎 | A-09 |
| e_air, e_water | 大气/水E值 | 企业人口数据→判定 | A-13, A-14, F-06 |
| risk_level | 综合风险等级 | 矩阵判定 | A-15, F-02, F-09, D-04 |
| pool_V1~V5 | 应急池核算参数 | 企业提供 | B-04~B-10, F-08 |
| sensitive_list[] | 周边敏感目标 | 企业确认 | A-13, A-14, F-06 |
| cases[] | 典型案例 | 搜索/知识库 | — |
| facilities[] | 防控设施 | 企业提供 | E-01, E-03, E-07 |

**⚠️ 红线：** 所有GLOBAL字段均通过 `D-01~D-09` 跨文档一致性检查，三份报告的值必须完全一致。发现不一致时，以应急预案中已确认的数据为准并通知其他报告更新。

## 文档结构（8章）

### 第1章 前言（≥200字）
- 企业简介、编制背景、评估目的简述

### 第2章 总论（≥800字）
- 2.1 评估目的与原则
- 2.2 编制依据（按三级分类：国家法规≥11条/地方法规≥6条/标准规范≥12条）
  - ⚠️ 标准时效性检查：所有标准号必须匹配标准时效性台账（19条核心标准）
- 2.3 评估范围与程序（引用HJ 941-2018第4条流程图）

### 第3章 资料准备与环境风险识别（≥4,000字）
- 3.1 企业基本信息（与预案一致→D-01通过）
- 3.2 项目概况（工艺/J/环保工程）
- 3.3 区域环境概况（地形/气象/水文/功能区划/质量现状）
- 3.4 周边环境风险受体（大气500m 5km人口+水下游10km→F-06, A-13, A-14）
- 3.5 涉及环境风险物质（化学识别/折纯/临界量→A-01~A-05, F-04, F-07, E-01~E-05）
  - ⚠️ 行业物质遗漏检查：含铬→查E-01/E-02；含氰→查E-03/E-04；含HF→查E-05
- 3.6 现有风险防控措施与应急资源
- **必须包含的表格：** 风险物质识别清单表、周边风险受体汇总表

### 第4章 突发环境事件及其后果分析（≥2,000字）
- 4.1 典型案例（≥3例同行业，含原因+后果+教训）
- 4.2 情景分析（化学品泄漏/火灾次生/废气故障/废水异常/危废泄漏）
- 4.3 后果分析（涉气+涉水影响范围及应急措施）

### 第5章 环境风险防控与应急措施差距分析（≥1,500字）
- 按环办〔2014〕34号第7章逐项分析
- 5.1 大气防控差距
- 5.2 水防控差距（含应急池核算V总公式→F-08）
- 5.3 危废管理差距（→E-09标准时效性）
- 5.4 监测预警差距（→F-10）
- 5.5 应急物资差距（→B-02）
- **必须包含的表格：** 应急池核算表（V₁~V₅分步）、差距分析检查表

### 第6章 完善风险防控的实施计划（≥800字）
- 整改项目清单（问题/措施/责任人/时限/资金）

### 第7章 环境风险等级划分（≥2,000字）— 规则引擎全量计算
- 7.1 风险等级分级程序（引用HJ 941-2018第4条）
- 7.2 环境风险单元划分（储罐区/车间/废水站/危废库/废气设施）
- 7.3 大气风险分级（Q值→M值→E值→矩阵等级→A-15）
- 7.4 水风险分级（同上→A-15）
- 7.5 综合风险等级确定（以高者定级→F-09, D-04）
- 7.6 重大危险源辨识（GB 18218-2018→A-16）
- **必须包含的表格：** Q值计算表、M值评分表（大气/水）、重大危险源辨识表

### 第8章 附图（6张）
- 地理位置图、平面布置及风险源分布图、环境风险受体分布图
- 雨污管网图、应急物资分布图、水环境功能区划图

## 数据计算规则（规则引擎硬算，LLM禁止参与）

### Q值计算
```python
def calculate_q(chemicals):
    # 涉气：HJ 941-2018附录A第一/二/三/四/六部分+第八部分部分
    # 涉水：HJ 941-2018附录A第三/四/五/六/七/八部分+第一/二部分中溶于水
    q = sum(c['purity']/100 * c['max_t'] / c['threshold']
            for c in chemicals if c['threshold'] is not None)
    return q
```
- 混合槽液必须分拆计算（A-03）
- 酸洗槽液必须计入Q值（A-04）
- 盐酸折纯：HCl量=盐酸量×浓度%（A-02）

### M值评估
- 生产工艺评分（HJ 941-2018表1）：重点监管化工工艺/高温高压/淘汰工艺
- 大气防控措施评分（表2）：毒性气体监控/防护距离/历史事件
- 水防控措施评分（表6）：逐项评分（截流/收集/清净废水/雨水/废水处理/排放去向/危废/历史事件）
- 注意电解/电镀工艺的M值关联评分（A-10）

### E值判定
- 大气E值：含周边居民和企业员工（F-06已通过人口确认）
- 水E值：下游10km敏感性分析

## 自检门（Self-Audit Gate）

生成DOCX后必须执行以下自检：

| 检查项 | 方法 | 通过标准 |
|:------|:----|:--------|
| 标准时效性 | 查标准台账 | 19条核心标准全部现行有效 |
| Q值自校验 | 规则引擎重算 | 与文档声明值误差<0.001 |
| M值自校验 | 规则引擎重算 | 逐项评分与文档一致 |
| E值自校验 | 规则引擎重算 | 判定正确 |
| 行业物质覆盖 | 遍历行业物质库 | C33含铬/含氰/含HF/含酸全部覆盖 |
| 数据一致性 | 对比GLOBAL表 | D-01~D-09全部PASS |
| 章节完整性 | 遍历章节 | 8章全部生成,字数达标 |
